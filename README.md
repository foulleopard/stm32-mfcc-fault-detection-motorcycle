# stm32-mfcc-fault-detection-motorcycle
This project showcases edge intelligent detection of mechanical faults in a motorcycle by obtaining audio &amp; Vibration signals via INMP441 &amp; MPU6050, a rigorous filtering operation to extract useful sound signals, feature extraction with MFCC and fault detection with Vector Similarity Analysis and Distance based classification.

Project was performed on STMcube IDE. MCU: STM32F411
